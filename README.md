## Projetos e pesquisa

### PaperCode FL --- Tradução de algoritmos científicos em código

**2º lugar · Hack Day São Paulo × FLUSP**

Projeto individual que utiliza inteligência artificial para interpretar
algoritmos descritos em artigos científicos e convertê-los em código
executável. Integra o modelo de linguagem Gemma 4, executado localmente
por meio do Ollama, a uma interface desenvolvida com Streamlit.

[Repositório](https://github.com/DaviTeobaldo/paper-code-fl)

### Spectrum Education --- Plataforma educacional

**4º lugar estadual (SP) · Hackathon da ETEC de Cotia, 2024**

Projeto em equipe voltado a estudantes com Transtorno do Espectro
Autista (TEA). A plataforma foi concebida com base em metodologias
ativas e estratégias psicoeducativas, tendo como referência a máquina de
ensinar de B. F. Skinner. Atuei na documentação e no desenvolvimento do
back-end, com React e Node.js.

### Iniciação Científica --- PICME / IME-USP

### Sistema de Gestão de Horários de Professores --- Trabalho de Conclusão de Curso

**ETEC de Cotia · nota máxima**

Sistema web para organização de horários de professores, considerando as
restrições institucionais. O back-end foi desenvolvido com Flask e
SQLAlchemy, enquanto o problema de alocação foi formulado
matematicamente e tratado por programação linear.

### House Prices --- Previsão de preços de imóveis

**Competição Kaggle**

Modelo de regressão para estimar preços de imóveis a partir de 79
características. O trabalho contempla um pipeline de preparação dos
dados, comparação de seis algoritmos e validação cruzada. A regressão
Ridge obteve RMSLE de 0,1145.

[Repositório](https://github.com/DaviTeobaldo/House-Prices-MachineLearning)

[Repositório](https://github.com/DaviTeobaldo/Projeto-DataScience-MachineLearning-ClassificacaoDeDoencaRenal)
